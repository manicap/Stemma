# Coding standard

**Dokument:** 09  
**Verze:** 0.1  
**Stav:** kostra k dopracování  
**Datum vytvoření:** 14. 7. 2026

## 1. Účel

Pravidla implementace projektu Stemma pro vývojáře, Codex a další AI nástroje.

## 2. Potvrzený technologický základ

- Python
- Django
- Django templates
- HTMX
- SQLite
- minimum vlastního JavaScriptu
- Git a GitHub

## 3. Oblasti k dopracování

- podporované verze Pythonu a Djanga,
- struktura projektu a Django aplikací,
- pojmenování,
- typové anotace,
- formátování a linting,
- formuláře a validace,
- HTMX fragmenty,
- databázové migrace,
- testy,
- bezpečnost,
- závislosti,
- pravidla pro Codex,
- commit messages,
- code review.

## 4. Dočasná pravidla

- řídit se PEP 8,
- preferovat čitelný a explicitní kód,
- nepřidávat závislost bez jasného přínosu,
- nepoužívat SPA,
- obchodní pravidla neukládat do šablon,
- nevkládat citlivé údaje do logů,
- nové funkce doprovodit testy,
- Codex nesmí bez schválení měnit architekturu.
